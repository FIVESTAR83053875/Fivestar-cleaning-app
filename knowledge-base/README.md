# 五星級專業清潔知識庫

這是一套由 AI 協助維護的 Markdown 知識庫，採用「原始資料、Wiki、維護規則」三層架構。

## 使用方式

1. 將新文件放入 `raw/inbox/`，原始檔只讀保存。
2. 告訴 AI：`請依 AGENTS.md 匯入 raw/inbox/檔名`。
3. AI 產生來源摘要，並同步更新相關主題頁、`index.md` 與 `log.md`。
4. 查詢時先讀 `index.md`，再讀相關頁面並標示來源。
5. 每月執行一次：`請依 AGENTS.md 對整個知識庫執行 lint`。

## 資料安全

- 客戶個資、帳號、密碼、API 金鑰、公司財務、健康與司法資料僅可放在私人儲存空間。
- 公開 GitHub 僅放去識別化內容與可公開資料。
- `raw/private/` 已列入 `.gitignore`，仍建議使用加密磁碟或私人儲存庫。
